# crates/afterray-store — the vault

The encrypted vault (`lib.rs`, ~6700 lines): a SQLCipher database plus per-artifact XChaCha20-Poly1305 files, with schema migrations, retention, FTS5 + semantic search, T1 slot cards, and GOP segment bookkeeping. `Vault` is synchronous — async callers (the daemon) must reach it through `afterrayd`'s `run_store`.

## Key anchors

- `Vault` — single writer + `ReadPool` (6 `query_only` readers) + `card_cache` + `artifact_io` `RwLock` (shared reads, exclusive put/delete/migrate).
- `Vault::open` — master key from `MacOsKeychainProvider` (Keychain service `dev.afterray.v0.vault`); blake3-derives the DB and artifact wrap keys (`DATABASE_KEY_CONTEXT`/`ARTIFACT_WRAP_KEY_CONTEXT`); runs `migrate`, reconcile, then `enforce_retention`. Non-macOS key providers hard-error.
- Encryption: `encrypt_artifact` — random DEK per artifact, XChaCha20-Poly1305, AAD binds purpose+id+content_type, magic `ARV1`; wrapped DEK in `artifacts`. Legacy `ARV0` files migrate in background (`run_artifact_maintenance`, spawned by the daemon).
- Schema: `SCHEMA_VERSION = 26`; `migrate` chains additive steps and `schema_meta` stamps the version. `summary_slot_geometry` is the slot-length history — one row per `(from_ms, duration_ms)`, seeded at schema 22 from the schema-20 `vault_meta.summary_slot_cutover_ms` marker. `audio_segments.transcription_*` is the durable ASR queue: old rows with transcript evidence migrate to `done`, rows without evidence stay recoverable. Also capture/search data, `slot_summaries`, `text_df`/`text_df_meta`, conversations, the vestigial `jobs` table.
- `input_events` (schema 23, content columns 25) — the shim's coalesced observations: the second fact stream, "what the user did". `insert_input_events` / `input_events_between` (a span counts when it overlaps at all). `kind` / `target_json` / `extra_json` stay **uninterpreted**: the T1 join owns their meaning and a newer shim's `kind` must round-trip. Since v2 a row holds content (`text`, and the field's `value` inside `target_json`) — the only guard is the shim's, at the source ([event-capture-v2](../../context/event-capture-v2.md)). Because events do expire, what is derived from them is frozen into `slot_summaries.acts_json` (`materialize_slot_acts`); not exposed via `SharedReadOnlyVault`.
- `edge_snapshots` (schema 24) — R3 edge trees: walked because the user changed scope, with **no moment, thumbnail or OCR**. Artifacts carry `EDGE_SNAPSHOT_CONTENT_TYPE` (`artifacts` has no purpose column, and the AAD binds content type). `prune_edge_snapshots_before` deletes rows **and their artifact files**. `slot_card` feeds them in as extra partition frames — they add text and nothing else.
- **Three persisted summary shapes**, told apart by `slot_summaries.schema_version` and **never** by which columns are null (every write path nulls the other shapes' columns): 1 = legacy `title + bullets`; 2 = description/threads/entities/decisions/not-captured (`V2_SLOT_SUMMARY_SCHEMA_VERSION`, still read, no longer written); 3 = `title`/`description`/`details` where `details` is one Markdown document (`SLOT_SUMMARY_SCHEMA_VERSION`, schema 26). A gate meaning "at least v2" must say `V2_…` — bumping the current constant in one would silently un-index every stored card. `details_sections` is what keeps a v3 body searchable (`find_slot_mentions` matches sections, not the whole document).
- Retention: `enforce_retention` — oldest-first eviction of non-favorite moments + orphaned GOP/audio, batches of 256, then the input events and R3 trees left behind the oldest surviving frame (`prune_input_events_before` / `prune_edge_snapshots_before`; no frames = no horizon = **no sweep**). Two clock deadlines: `prune_signal_gaps` (`SIGNAL_MARKER_RETENTION_MS` 48h — markers are bookkeeping about the recorder, not a record of the user) and raw `input_events` (`RAW_EVENT_RETENTION_MS` 48h), which the daemon deletes only after `materialize_slot_acts` has frozen the shape of that window — the words go, the counts stay ([why](../../docs/decisions/active/product/2026-08-20-raw-input-events-expire.md)).
- Search: `search_filtered` — FTS5 bm25 via `match_query`; `SearchFilter` narrows time + app **in SQL, before ranking** (filtering afterwards makes older evidence unreachable). `search` is the unfiltered wrapper. `semantic_search`/`fuse_search_results` have no callers: no vector index.
- `search_index.rs:52 index_text` / `:110 match_query` — CJK bigram folding for FTS5.
- `find_slot_mentions` / `match_slot_mention` — index over stored v2/v3 summaries (entities, threads, titles, and a v3 body's sections); same `SearchFilter`. Candidates are matched and ranked **against JSON values via `json_each`**, never the serialised card: raw `LIKE` also hit serde's key names (`"text"`, `"name"`, `"prose"`), filling the window with rows the exact matcher then dropped. A raw `LIKE` on the longest whitespace-free token stays as a cheap superset gate — a tighter one drops rows silently, since the decision happens in `fold_for_match`'s whitespace-free space. `slot_title_covering` uses the row's own `slot_end_ms`; never recompute bounds — the geometry may have changed since the row was written.
- `slot.rs` — T1 cards: `slot_bounds_in` resolves an instant against the `SlotSegment` history (a slot is clipped at a segment boundary, never straddles one), plus `build_slot_card_with_end` (no events) / `build_slot_card_with_acts` (joined) / `build_slot_card_with_edges` (joined + R3 trees), v2/v3 parsing + citation grounding (`parse_t2_card_v3`, `ground_t2_details`), `SlotSummaryState`. Pure and deterministic — keep it model-free and unit-testable.
- **Per-slot rules are absolute, never a share of the slot** — length is a user setting, so a share lets that setting decide the outcome. The activity gate is a floor (`GATE_MIN_ACTIVE_MS`); the prompt budget scales with the slot (`prompt_budget_for`), capped by the model's probed window passed in from the daemon — a prompt past the real window is cut unread.
- `acts.rs` — joins the two fact streams (pure): hit-test → LCA → expand to `ENGAGED_MIN_WINDOW_AREA_RATIO` (0.10, **the only knob**), `split_act_runs`, `fold_acts`, `unavailable_spans`, `no_input_ratio`. Fails open: no hit / no window frame → no scope, no partition. **Read [acts-join](../../context/acts-join.md) before touching it: six invariants there may not be weakened.**
- `gop.rs` — `PackPolicy` (hot window 2h, keyint 30), `fold_pack_runs` (one open run per resolution so dual-display desks do not collapse into 1-frame GOPs; `first_packable_run` / `packable_frame_count` skip singles — backlog uses the latter), `commit_gop` (can fail `StoreError::GopStale` when retention races), `rollback_orphan_gops`, `drop_unpinned_stills`.
- `ax_compress.rs` — zstd-3 AX/edge JSON; `read_artifact` decompresses by magic. Keep `root`: OCR crop / T1 / acts-join still parse it.
- `infoscore.rs` (IDF scoring against `text_df`), `activity.rs` (AX parsing/activity spans), `memory.rs` (AX digests), `pipeline_bench.rs` (`#[ignore]`d manual bench).

- `compute_backlog(now, policy)` counts the durable background pile for the dashboard. Archive stills are `packable_frame_count` over `list_pack_candidates_read` (reader pool, same `PACK_CANDIDATE_PREDICATE`, then fold — leftover 1-frame runs do not count). The packer keeps `list_pack_candidates` on the writer. Transcripts reuse `AUDIO_CLAIMABLE_PREDICATE`. **Share those consts, never hand-copy a selection rule**. Packed moments are excluded (their JPEG is gone) and `unindexed_moments` looks back one day. Cache the result.
- `has_untranscribed_audio_between(from, to)` / `asr_health(now)` — what the T2 gate asks before sealing a card it can never revise: is a transcript still coming for this window, and is ASR alive at all. Reader pool. Both read `AUDIO_UNTRANSCRIBED_PREDICATE`, a **strict superset** of `AUDIO_CLAIMABLE_PREDICATE` (no backoff clause, includes `running`) — "may the sweeper claim this now" and "is a transcript still coming" are different questions. Its state list is load-bearing: `complete_audio_transcription` marks silence `done` with **no evidence row**, so the `NOT EXISTS` half alone would call every quiet segment untranscribed forever. Health counts a `done` row as the success (the worker returned, even if what it returned was silence) and clamps both instants to `now`. There is **no retry cap** anywhere in this codebase — segments retry forever — so `exhausted_segments` counts against `AUDIO_BACKOFF_SATURATION_ATTEMPTS` (6), the point where the daemon's `1 << min(attempts, N)` backoff stops growing; the daemon shares the same const.
- `recent_summary_runs(limit)` reads the `latency_ms` already persisted on `slot_summaries` so the compute dashboard can say how long summaries usually take. There is no index on `produced_at_ms`: the daemon reads it **once at startup**, never on a polling path.

## Build / test

- `cargo test -p afterray-store`; manual bench: `cargo test -p afterray-store -- --ignored --nocapture`.

## Watch out

- **Writer/reader split**: writes take `Vault.connection` (the Mutex); reads should use `readers.get()`. A write on a reader errors loudly — intentional.
- **Any moment-deleting path must call `flush_card_cache`** or a settled slot card resurrects deleted frames. `delete_history` must also drop overlapping `slot_summaries`, `input_events` **and `edge_snapshots` (files included)** — one privacy invariant, four layers: forgetting a window has to take the cards, the acts, and the R3 trees with the frames. The trees belong to no moment, so no frame deletion can reach them.
- **FTS is not raw text**: write via `insert_text_evidence` (applies `index_text`), query via `Vault::search` (applies `match_query`). Hand-written `evidence_fts` inserts/queries silently break CJK.
- **Encryption AAD binds artifact id + content_type + purpose** — renaming/retyping an artifact makes it undecryptable. The `ARV0` legacy path must stay until `run_artifact_maintenance` completes.
- **Semantic search has no callers**: full scan, no vector index, disabled pending redesign ([agent-tools](../../context/agent-tools.md)). If it returns, `SEMANTIC_MIN_SIMILARITY` + matching `model_version` remain contract.
- Secrets: `store_secret`/`load_secret` use Keychain service `dev.afterray.v0.secrets` (e.g. `LLM_API_KEY_SECRET`); non-macOS hard-errors.
